# Progress Manager

단순 문서·스타일 수정에는 보드를 필수로 만들지 않습니다.
여러 단계의 작업에서는 [템플릿](../../templates/progress_template.md)을 사용합니다.

- 저장소 루트에서 `bash .agents/hooks/init.sh`로 없는 파일만 생성합니다. 기존 보드·로그를 덮어쓰지 않습니다.
- 진행 중 작업은 해당 섹션에서 이어갑니다. 새 작업은 기존 내용을 보존하고 새 섹션을 추가합니다.
- 사용자 요구, 제외 범위, 관련 `.agents/Yeolo-SPEC/` 문서, 관찰 가능한 인수 기준, 파일별 작업, 검증 명령을 기록합니다.
- 역할 상태는 대기/진행중/완료/차단/생략으로 구분합니다. 생략·차단은 이유를 적습니다. Tester 완료와 테스트 PASS는 별개입니다.
- 검증에는 명령, cwd, 종료 코드, 범위와 결과를 기록합니다. 미실행을 PASS로 쓰지 않습니다.
- 여러 에이전트가 일할 때 주 에이전트만 공유 보드를 편집합니다. 담당자는 결과를 전달합니다.
- 요청 조건과 필수 검증이 충족되면 DONE, 진행 중이면 IN_PROGRESS, 필요한 입력·환경 때문에 진행할 수 없으면 BLOCKED를 사용합니다.
- 보드는 Git에서 제외되므로 최종 답변에도 중요한 결과와 미검증 사항을 남깁니다.
