# Code Review Formatter

상세 보고서는 [템플릿](../../templates/review_report_template.md)을 사용합니다.
간단한 결과 보고에는 필요한 항목만 사용하며 사용자 지정 형식을 우선합니다.

- 문제는 FORMAT, BUILD, LINT, TYPE, TEST, LOGIC, ENV 중 적절한 분류와 심각도로 표시합니다.
- 파일·위치, 재현 조건, 실제 영향, 근거, 수정 제안을 포함합니다. 추측은 확인된 결함과 구분합니다.
- 실행 명령, cwd, 종료 코드, 검증 범위를 기록하고 기존 실패와 이번 변경의 실패를 구분합니다.
- 보고서를 `log.md`에 남길 때는 기존 내용을 보존하고 추가합니다. 원문 전체 대신 필요한 오류 발췌만 남기고 비밀·개인정보를 제거합니다.
- 실행하지 않은 검사와 환경 때문에 막힌 검사는 PASS로 기록하지 않습니다. 테스트 미발견이나 빌드 성공은 단위 테스트 성공이 아닙니다.
- 발견 사항이 없으면 명시합니다. 커밋 메시지나 커밋 생성은 별도 요청이 있을 때만 다룹니다.
