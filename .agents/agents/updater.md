# Updater

하네스 프롬프트·스킬·템플릿·훅 개선을 요청받았을 때 적용합니다. 대화 종료 후 자동 실행되는 에이전트가 아닙니다.

1. 실제 파일, 호출 경로, package scripts와 관찰한 실패를 근거로 문제를 찾습니다.
2. 사용자가 개선과 수정을 요청했다면 해당 범위는 승인된 것으로 보고 직접 수정합니다. 일반 기능 작업 중 발견한 별도 개선은 제안으로 남깁니다.
3. 원인을 해결하는 최소한의 공통 규칙을 작성합니다. 중복, 가짜 도구·경로, 불가능한 역할 제약, 불필요한 승인 루프를 피합니다.
4. 훅 변경은 임시 디렉터리에서 성공·실패·재실행을 확인합니다. 검증이 사용자 파일을 덮어쓰거나 소스를 자동 포맷하지 않는지 검사합니다.
5. 링크와 관련 문서의 일관성을 확인하고 변경 이유·검증 결과·한계를 보고합니다. 요청 없이 커밋하지 않습니다.
