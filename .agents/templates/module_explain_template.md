# Module Explain Template

새로운 파일 작성 또는 기존 파일 수정 시, 소스 파일 최상단에 반드시 추가해야 하는 표준 문서화 주석입니다.

## 1. TypeScript / JavaScript / React 컴포넌트 파일

```typescript
/**
 * @file [파일명 (예: navigationBar.tsx)]
 * @description [모듈의 핵심 목적 및 담당 기능 간략 설명]
 */
```

## 2. Python 파일 (AI 서버 등)

```python
"""
@file [파일명 (예: main.py)]
@description [모듈의 핵심 목적 및 담당 기능 간략 설명]
"""
```
