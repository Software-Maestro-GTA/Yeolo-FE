# 서울 여행 릴스 예시

`seoul-day.mp4`는 사용자가 제공한 2026-10-11 여행 사진 7장으로 제작한
릴스 시작 화면의 반복 재생 영상입니다. 원본 사진은 저장소에 포함하지 않습니다.

- 순서: 광화문 광장 → 진중우육면관 광화문점 → 대한민국역사박물관 → 꼬르꼬바두 본점 → 청계천 → 파작 청계천 → 교보문고 광화문점.
- 형식: 720 × 1280, H.264, 24fps, 26.5초, 636프레임, 오디오 없음.
- 구성: 소개 1.5초 / 장소별 사진 3초 × 7 / 지도 4초. 마지막 장면은 없습니다.
- 첫 제목 화면과 장소 사진 7장 모두 확대·축소 없이 고정 구도로 표시합니다. 지도 번호·장소명 순차 등장은 유지합니다.
- 소개는 `광화문 여행 코스 7곳` 제목과 `함께 놀기 좋은` 설명을 하단에 배치합니다. 소개 지역명은 광화문, 실제 도시는 서울로 구분합니다. 긴 제목도 두 줄까지 표시되도록 소개 텍스트 공간을 확보합니다.
- 장소 화면은 제목 옆 번호, 하단 흰 제목과 두 줄 설명, 검정→투명 선형 그라데이션을 사용합니다. 편집기에서 장소별 설명을 수정하거나 비울 수 있고 사진 교체·날짜 이동에도 보존됩니다. 두 줄 설명을 읽도록 장소당 3초를 확보했습니다.
- 파작 장면은 imagegen으로 세로 구도를 조정하여 금색 PAZAC 간판이 화면 중앙에 보이도록 제작했습니다. 편집 결과는 완성 MP4에 반영되어 있으며 제작 중간 이미지는 보관하지 않습니다.
- 지도는 Google Maps SDK 원본 전체를 668px 둥근 카드에 맞추고 로고를 유지합니다. 연결선은 없으며 번호와 장소명이 0.35초 간격, 0.18초 페이드로 하나씩 나타나 남아 있습니다.
- 이름표는 카드 내부에서 다른 번호·이름표 및 하단 로고와의 겹침을 줄이도록 배치합니다.
- 마지막 지도 아래에 해당 여행 날짜 `2026. 10. 11.`과 `대한민국, 서울에서`를 두 줄로 가운데 정렬합니다. 지역 문구는 예시의 country·city 및 앱에서 선택한 코스의 국가·도시에서 만들며 공통 플랜 옵션으로 전달합니다. 날짜가 없거나 잘못된 경우 현재 날짜로 대체하지 않습니다. 별도 마지막 장면은 추가하지 않습니다.
- 앱 편집 목록 상단에 `코스 소개`와 `코스 설명` 입력을 항상 표시하고 각각 바꿀 수 있습니다. 소개 제목은 여행 코스 제목, 장소 제목은 코스의 장소명으로 기본 입력하며 직접 비운 값도 보존합니다. 장소 제목이 비어 있으면 해당 사진의 번호도 숨깁니다(지도 번호는 유지).
- 편집 버튼으로 항목 편집 모드를 열고 제목 오른쪽의 위·아래·삭제 아이콘으로 항목을 이동하거나 삭제합니다. 초기화→완료 순서로 버튼을 배치합니다. 초기화는 확인창에서 동의한 뒤 현재 날짜의 원래 순서와 삭제된 항목을 복원하며 추가한 사진과 수정한 문구는 유지합니다. 취소·닫기·배경·뒤로 가기는 변경을 적용하지 않습니다. 제목행과 아이콘 버튼은 원래 23px 높이를 유지해 사진 첨부 영역과 입력 영역의 정렬을 맞추고 편집 전후 카드 높이가 변하지 않게 합니다. 사진·제목·설명은 해당 항목에 붙어 있으며, 목록 순서에 따라 영상과 지도 번호·등장 순서가 바뀝니다. 날짜별 초안을 보존하고 실제 좌표는 유지합니다. 순서 변경은 지도 배경을 재사용하며, 삭제 시 남은 장소로 지도 범위를 다시 계산·캡처합니다. 새 지도 준비 전에는 미리보기·내보내기를 막으며 이전 캡처는 폐기합니다. 저장된 원래 코스는 변경하지 않습니다.
- 제작 화면은 실제 기기 인코딩 작업 동안 표시합니다. 네이티브 진행률은 약 100ms 간격으로 전달하고 게이지는 300ms 애니메이션으로 실제 진행률 사이를 보간합니다. 파일 마무리가 끝나기 전에는 100%로 표시하지 않으며 인위적인 대기 시간을 넣지 않습니다.
- 예시는 실제 SDK 지도 캡처와 앱의 `buildReelPlan`·이름표 배치 함수·iOS 렌더러로 제작했습니다.
- 모든 장면의 우측 상단에 Marketing Design `Frame 1029`의 흰 심볼을 표시합니다. 게시물 배치를 720px로 비례 조정한 약33×39px, 위34px/오른쪽37px 여백이며, 원본은 `assets/branding/reel-mark.svg`입니다.
- 네이티브 렌더러 버전은 7입니다. 새 내보내기 기능을 설치 앱에 반영하려면 iOS/Android 네이티브 재빌드가 필요합니다.
- 포스터는 최종 영상 0.6초 프레임입니다. 시작 화면은 `LoopingVideo`로 무음 반복 재생하며 모션 감소 설정·백그라운드·재생 실패를 처리합니다.

## 좌표 근거

영상 제작에 사용한 위치의 근거입니다(2026-10-28 확인).

- 1·2·6번: 제공된 사진의 GPS EXIF.
- 3번: [대한민국역사박물관 좌표](https://ko.wikipedia.org/wiki/대한민국역사박물관).
- 4번: [꼬르꼬바두 본점 지도](https://polle.com/place/4INNEu)의 좌표. 등선재점과 구분했습니다.
- 7번: [교보문고 공식 매장안내](https://store.kyobobook.co.kr/store-info)의 광화문점 좌표.
- 5번: 사용자 요청으로 4번 꼬르꼬바두 본점과 기존 5번 [청계광장](https://ko.wikipedia.org/wiki/청계광장) 사이(37.568932, 126.985762)로 옮겼습니다. 파작(6번) 핀과 겹치는 중간점 대신 4번에서 기존 5번 방향으로 1/3 지점을 사용했습니다. 정확한 사진 촬영 지점을 의미하지 않습니다.

Google Places Text Search는 기존 키에서 `API_KEY_SERVICE_BLOCKED`여서 사용하지 않았습니다.
Google Place ID를 만들거나 추정하지 않았으며, 앱의 영상 생성은 사진이나 원본 EXIF를 서버로 업로드하지 않습니다. 파작 이미지 편집에는 별도로 imagegen을 사용했습니다.

## 편집 의도와 성과 확인

첫 1.5초에 지역과 장소 수를 보여주고, 장소 사진 이후 지도에서 종료합니다.
26.5초는 이 예시에 선택한 편집값이며 조회수나 좋아요 증가를 보장하는 최적값은 아닙니다.
