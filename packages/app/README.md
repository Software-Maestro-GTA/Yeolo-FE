# @yeolo/app

여로의 React Native (Expo) 기반 모바일 앱 패키지입니다.
공통 모듈인 `@yeolo/common`과 연동하여 통합 비즈니스 로직을 사용합니다.

---

## 폴더 구조

```text
packages/app/
├── src/
│   ├── components/   # 앱 공통 및 도메인별 UI 컴포넌트
│   ├── context/      # 인증 및 전역 상태 콘텍스트
│   ├── hooks/        # React Query 및 커스텀 훅
│   ├── navigation/   # 라우팅 및 네비게이션 정의
│   ├── screens/      # 화면 컴포넌트 (Home, Login 등)
│   ├── services/     # Native SDK 및 세션 유틸리티
│   └── App.tsx       # 모바일 앱 메인 컴포넌트
├── assets/           # 아이콘 및 스플래시 이미지 에셋
├── app.config.js     # Expo 동적 설정 파일
├── app.json          # Expo 앱 전역 설정 및 메타데이터
├── eas.json          # EAS 빌드 프로필 설정
└── package.json
```

---

## 개발 모드 실행

개발 서버 실행 전 Android 에뮬레이터 또는 iOS 시뮬레이터가 기동되어 있어야 합니다.

```bash
# packages/app 디렉터리 내에서 실행 시

# Android 개발 모드 실행
yarn android

# iOS 개발 모드 실행 (macOS 전용)
yarn ios
```

## MyRealTrip 제휴 예약

[공식 API 문서](https://docs.myrealtrip.com/#/api/intro)를 기준으로 앱에서 파트너 API를 직접 호출합니다.

1. MyRealTrip 파트너 API 키를 발급받습니다.
2. `packages/app/.env.development` 또는 `.env`의 `MY_REAL_TRIP_API_KEY`에 키를 입력합니다. 프로덕션 빌드 스크립트는 `.env.production`을 명시적으로 로드하므로 배포 환경에도 같은 변수를 설정합니다.
3. 환경 변수 변경 후 Expo를 재시작합니다. Jest/웹에서 공통 모듈을 사용할 때는 `yarn workspace @yeolo/common build`를 실행합니다. 배포 앱은 키 변경 시 새 빌드/업데이트가 필요합니다.

이 변수는 `app.config.js`의 `extra.myRealTripApiKey`를 통해 **앱 번들에 포함되어 추출할 수 있습니다**. `.env`는 Git에서 제외하며 실제 키를 커밋하지 않습니다. 서버를 통한 호출 대신 앱 직접 호출을 선택한 구성입니다. 키는 MyRealTrip에만 전송하며 Yeolo 로그인 토큰을 사용하지 않습니다.

- 예약은 앱 공통 레이아웃의 일반 화면으로 열립니다. 상단 안전 영역, 이전 화면 복귀, 하단 홈·탐색·생성·프로필 내비게이션을 유지합니다.
- 홈: 항공권·숙소·투어/티켓 검색. 최근 코스가 있으면 목적지와 일정을 채웁니다.
- 코스 상세: 항공권/숙소 배너와 투어·티켓 버튼. 종료일은 시작일 + 여행 일수 - 1일입니다.
- 장소 상세: 투어·티켓 버튼으로 진입하면 장소명으로 즉시 검색하고 결과를 표시합니다. 숙소 카테고리는 해당 코스 지역의 숙소 검색을 제공합니다. 특정 장소의 입장권이 반드시 존재한다는 뜻은 아닙니다.
- 항공권: 도시/공항 검색 결과에서 출발·도착 공항을 직접 선택합니다. `airport.code`로 왕복 항공 랜딩 URL을 생성하고 `POST /v1/mylink`로 단축 링크를 생성합니다.
- 숙소: 국내/해외와 지역을 선택한 후 체크인·체크아웃·성인 인원으로 검색합니다. 당일 코스는 체크아웃을 직접 수정해야 합니다.
- 투어·숙소: 검색 결과를 페이지당 최대 20개씩 표시하고 목록 끝에 다다르면 다음 페이지를 이어 불러옵니다. 사용자가 고른 상품의 `productUrl`을 마이링크 API에 전달합니다.
- 김포–제주처럼 항공 랜딩 API가 HTTP 400을 반환하는 노선에는 마이리얼트립 홈 제휴 링크로 직접 검색하는 대체 버튼을 제공합니다. 홈 이동 후 항공권 검색 조건을 다시 입력해야 합니다.
- 예약 상품 또는 항공권 검색을 선택할 때 제휴 링크를 생성합니다. 검색 실패/빈 결과는 화면 내 안내 및 재검색을 제공하며, 일반 URL로 조용히 대체하지 않습니다.
- 키 미설정/권한 오류/요청 제한/네트워크 및 브라우저 오류를 처리합니다. 요청별 제한 시간은 15초이며 중복 요청과 닫힌 창의 뒤늦은 링크 열기를 방지합니다.

날짜는 숫자 8자리로 입력하면 `YYYY-MM-DD` 형태로 표시됩니다. 항공권은 왕복·성인, 숙소는 성인 조건의 검색이며 최종 가격·객실·소아 동반 등 세부 조건은 마이리얼트립에서 확인합니다. 개발 키로 숙소·투어·국제선 제휴 링크 생성은 확인했습니다. 실기기에서 예약 페이지와 최종 제휴 귀속 확인은 배포 전 별도로 필요합니다.
